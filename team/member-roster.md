## 加入流程（给组长）

1. 新成员注册 GitHub 并私发用户名。
2. 组长在 GitHub 仓库设置中邀请该用户为 collaborator。
3. 新成员按 `team/division-of-labor.md` 的 Onboarding 清单完成环境并填写本表（提交 PR）。
