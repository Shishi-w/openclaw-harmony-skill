# 项目路线图

> 按阶段拆解目标与可交付成果，配合 `05-protocols/task-board.md` 的看板使用。时间仅建议，可按实际进度调整。

## 阶段 0：启动期（第 1-2 周）
- 搭建仓库、环境（Git/OpenClaw/HarmonyOS）、分工确认、成员 Onboarding 完成。
- 明确两方向目标与评测指标体系。
- **里程碑**：README/分工/环境文档齐全，全员环境可用。

## 阶段 1：调研期（第 3-5 周）
- 文献综述推进（C2 牵头）；OpenClaw Skill 机制源码级拆解。
- 方向 A：盘点 OpenClaw 内置/常用 Skill，产出 Skill 分类清单。
- 方向 B：完成需求分析，产出 IR Schema v0 草案与 Host Interface 初始接口。
- **里程碑**：skill 清单 + 综述初稿 + IR 草案评审。

## 阶段 2：验证期（第 6-10 周）
- 方向 A：跑通 ≥3 个代表性 Skill（覆盖三类之一）。
- 方向 B：VM 运行时在 PC/OpenClaw 宿主跑通 1 个示例 Skill（M2）。
- 建立评测基准集（benchmark.md）。
- **里程碑**：两方向各有可运行演示 + 首批评测数据。

## 阶段 3：深化期（第 11-15 周）
- 方向 A：批量移植，累计 ≥5 个 Skill，沉淀批量经验。
- 方向 B：HarmonyOS 适配器（M3）+ 多 Skill 对比评测（M4）。
- 两方向对比数据完整（comparison.md）。
- **里程碑**：鸿蒙宿主演示 + 完整对比评测报告。

## 阶段 4：输出期（第 16 周起）
- 整理迁移工具链与文档。
- 撰写论文草稿 / 项目报告，复盘与归档。
- **里程碑**：论文草稿 + 最终报告 + 文档归档。

## 跟踪方式
- 每周例会对照看板更新进度。
- 每个里程碑完成后打 git tag（如 `v0.1`）并归档。
